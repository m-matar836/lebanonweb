# V70 — اعتماد الكل

تمت إضافة زر **اعتماد الكل** لحسابي `admin` و`manager` في:

- سجل التقارير
- سجل الدوام
- سجل حركات المواد

الزر يعتمد فقط السجلات **قيد المراجعة**، ولا يغير أي سجل حالته **مرفوض** أو **معتمد**.

صلاحيات المدير تبقى ضمن نطاق فريقه/الموظف المحدد، وصلاحية التنفيذ يعاد التحقق منها في الخادم.
